# Feature Specification: 房东出租 / 收租管理小程序

> 来源：`./功能点.md`（端到端头脑风暴已归档）。本文件只描述 **what / why**，不含技术栈。
> 分支：`001-landlord-rental-mgr`。

## Summary

为手握多套房源的房东提供**出租 / 收租 / 费用 / 事务**的一站式管理（**先以 Web 前端、手机比例仿真小程序外观呈现；后续再做微信小程序**）。
将房源分为 `待租` 与 `已租` 两大板块，覆盖从收房建档 → 挂盘带看 → 签约 → 收租 →
退租清算的完整生命周期，并把所有凭证类文件（房产证 / 合同 / 缴费凭证）以附件形式留痕。

## User Scenarios

- **S1 建档**：房东录入一套新房源（昵称、地址、面积、户型、图册、房产证），归入待租。
- **S2 放租**：房东在多个渠道挂盘，记录联系人 / 价格策略，预约并登记带看，收集双向反馈。
- **S3 签约**：达成意向 → 收意向金 → 上传合同 → 交钥匙 → 房源转入"已租"。
- **S4 收租**：系统按期生成账单（租金 + 物业费 + 停车费），房东记录实缴与凭证，逾期可提醒。
- **S5 费用交接**：入驻 / 退租时登记水电气物业户号与表底，生成交接单。
- **S6 维修**：登记屋内维修与小区物业维护，时间线留痕。
- **S7 退租**：验房、费用清算、押金结算、账户过户、收回钥匙，生成退租交接单。
- **S8 总览**：首页看房源数 / 应收已收欠收 / 空置率；提醒中心聚合带看、交租、到期。

## Functional Requirements

### 房源基础（FR-1xx）
- FR-101 房源 CRUD：昵称、房产证全称、地址、面积、户型、楼层、朝向、装修、图册、标签、状态（待租/已租）。
- FR-102 图册与户型的视觉化呈现（缺失点#8）。
- FR-103 房产证等文件作为附件挂载（见 FR-7xx）。

### 待租（FR-2xx）
- FR-201 渠道管理（中介/自媒体/论坛…）：联系人、佣金、挂盘状态、曝光。
- FR-202 价格策略：各渠道挂盘价、最低接受价。
- FR-203 带看：预约、潜在租客、来源渠道、带看人、状态（待带看/完成/取消/爽约）+ 记录。
- FR-204 双向反馈：租客对房反馈 + 房东对租客评估。
- FR-205 签约流程状态机：洽谈 → 意向金 → 签约 → 交钥匙 → 转已租。
- FR-206 空置与定价分析：空置天数 / 成本、同小区参考、渠道转化（缺失点#4）。

### 已租 / 租约（FR-3xx）
- FR-301 租约：租期起止、租金、押金、缴费方式、合同文件。
- FR-302 租约状态：生效中 / 即将到期 / 已退租 + 续租/退租标记。
- FR-303 押金收付与退租扣款明细、退还记录。
- FR-304 租客档案：微信/手机/身份证/户口本/职业收入/宠物/人数/紧急联系人/来源。
- FR-305 续租流程：到期提醒 + 新合同（缺失点#3）。
- FR-306 退租清算：验房、费用清算、押金结算、账户过户、收钥、退租交接单（缺失点#2）。

### 收租与账单（FR-4xx）— 核心
- FR-401 周期性账单生成（租金+物业费+停车费），含应缴日、周期（月/季）。
- FR-402 缴费状态：待缴 / 已缴（实缴日+凭证）/ 逾期。
- FR-403 逾期催收提醒 + 催缴记录（可选滞纳金）。
- FR-404 收据/凭证上传归档；月度/年度汇总导出。

### 费用账户与交接（FR-5xx）
- FR-501 水/电/燃气/物业/宽带：户号、入驻读数、退租读数、过户状态。
- FR-502 入驻 / 退租交接单：设施清单 + 表底确认（缺失点#5）。

### 维修与物业（FR-6xx）
- FR-601 屋内维修记录（时间/问题/处理人/费用/状态/凭证）。
- FR-602 小区物业维护记录（与屋内维修区分）。

### 文件附件（FR-7xx）— 底层能力
- FR-701 图片/PDF/Word 上传并预览（Web 版前端预览/本地暂存；后续接云存储），挂载到对应房源/记录。

### 全局（FR-8xx）
- FR-801 搜索/筛选（状态、区域、渠道、关键词）。
- FR-802 提醒中心 + 订阅消息（交租日、带看、到期、欠缴）（缺失点#6）。
- FR-803 数据统计（出租率、平均租金、空置天数、渠道转化）。
- FR-804 数据导出 Excel/PDF（缺失点#7）。

## Non-Functional Requirements

- NFR-1 仅单人使用，数据隔离到当前用户（云开发 openid）。
- NFR-2 不上线、不接真实支付；免费环境资源克制。
- NFR-3 关键操作（账单计算、金额）可单测、结果确定。
- NFR-4 附件上传走鉴权，下载域名受控，防越权/SSRF。
- NFR-5 交互：列表卡片 + 状态标签 + Tab 分段详情 + 时间线 + 日历。

## Edge Cases

- EC-1 同一房源先待租后已租，再退租重新挂盘：状态闭环与数据不丢。
- EC-2 退租时押金不足以抵扣损坏：支持"押金结算为欠房东款"。
- EC-3 多渠道同时挂盘成交：仅一个渠道转签约，其余自动下架。
- EC-4 账单生成日恰逢租约中途变更（续租/退租）：按新周期重算。
- EC-5 上传非预期文件类型 / 超大文件：前端校验 + 云存储限制。
